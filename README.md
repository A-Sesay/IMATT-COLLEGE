# IMATT College ERP Prototype

This project contains a responsive login page and a role-based dashboard prototype for an integrated academic ERP administrative module.

## Pages

- `index.html` – login screen with a two-panel design
- `dashboard.html` – dashboard screen for different user roles
- `styles.css` – shared styling for the application
- `script.js` – role-specific dashboard rendering and login navigation

## Run locally

Open the folder in a browser, or serve it from the project directory:

```bash
cd d:/dissert
python -m http.server 8000
```

Then visit:

- http://localhost:8000/
- http://localhost:8000/dashboard.html

## Included roles

- Administrator
- Registrar
- Exams Office
- Finance Office
- Secretary
- Head of Department
- Board Chairman
